## 🧘‍♀️ Features:

- GPT-3.5 based conversational intelligence  
- Speaks every reply in **Hindi** using soft feminine voice  
- Stores every interaction in a sacred JSON memory  
- Downloadable voice responses  
- Fully browser-based and mobile-ready  
- Deployable via [Streamlit](https://streamlit.io/)

---

## 🛠️ How to Use

### 1. Upload these three files to GitHub:
- `app.py`
- `requirements.txt`
- `Shanti_Eternal.json`

### 2. Create a free [Streamlit Cloud](https://streamlit.io/cloud) account  
- Deploy your GitHub repo  
- Set main file path to `app.py`
